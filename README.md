# Концептуальна модель даних бібліотеки

Система для обліку каталогу книг, читачів, видач, бронювань і штрафів (мульти-примірникова бібліотека).

## Артефакти
- `spec.md` — специфікація (сутності, вимоги, NFR, трасування).
- `DEFENSE.md` — захист рішень (точка входу для рев'ю).
- `docs/adr/` — архітектурні рішення (MADR).
- `task-1/` … `task-5/` — ER, Use Cases, Sequence, Activity, Component.
- `ai/` — промпти до AI та фідбек.

## Діаграми
Mermaid/PlantUML блоки в Markdown рендеряться GitHub безпосередньо (PNG не комітиться).

## Історія
Робота виконана ітераціями (15 комітів, 16–20.11.2026) з аудитами та виправленнями. Деталі — у `DEFENSE.md`.
