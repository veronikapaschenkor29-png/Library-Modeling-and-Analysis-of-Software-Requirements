# 2. BOOK_AUTHOR як асоціативна сутність з author_order

* Статус: прийнято
* Дата: 2026-11-23

## Контекст та постановка проблеми
Книга може мати кількох авторів, а автор — кілька книг. Потрібно зберегти порядок авторів на обкладинці.

## Розглянуті варіанти
* **Варіант 1:** Зберігати авторів у масиві/рядку в `BOOK`.
* **Варіант 2:** Окрема асоціативна сутність `BOOK_AUTHOR` з атрибутом `author_order`.

## Рішення
Обрано **Варіант 2** — асоціативна сутність `BOOK_AUTHOR`.

### Позитивні наслідки
* Зв'язок M:N між `BOOK` і `AUTHOR` без дублювання.
* Атрибут `author_order` зберігає порядок авторів.
* Можна додавати інші атрибути зв'язку (роль автора) без зміни схеми.

### Негативні наслідки
* Додатковий `JOIN` при вибірці авторів книги.
