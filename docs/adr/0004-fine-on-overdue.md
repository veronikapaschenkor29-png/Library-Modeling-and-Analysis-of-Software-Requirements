# 4. FINE за простроченням як extend від повернення

* Статус: прийнято
* Дата: 2026-11-23

## Контекст та постановка проблеми
Штраф створюється лише при поверненні простроченої видачі. Потрібно визначити, коли і як створюється `FINE`.

## Розглянуті варіанти
* **Варіант 1:** Створювати `FINE` при видачі, якщо прогнозується прострочення.
* **Варіант 2:** Створювати `FINE` при поверненні, якщо `returned_at > due_at` (extend від «Повернути книгу»).

## Рішення
Обрано **Варіант 2** — `FINE` створюється при поверненні (extend).

### Позитивні наслідки
* Штраф відповідає фактичному простроченню, а не прогнозу.
* `FINE` є необов'язковим розширенням UC «Повернути книгу».
* Сума штрафу розраховується за фактичною затримкою.

### Негативні наслідки
* Потрібна перевірка терміну при поверненні, що ускладнює UC.
